# WordFinder 使用说明

适用：Windows 10 x64 办公电脑；当前构建在 Windows 11 x64 上完成验证，Windows 10 实机验收尚待完成。无须安装 Excel、Python 或 .NET。打开原文件需要电脑有相应的关联程序。

## 第一次使用

1. 将 `WordFinder.exe` 放在本机可执行目录，双击运行。
2. 点击“目录和设置”。“添加文件夹”可浏览目录；也可粘贴文件夹路径再点击添加。可选多个本机目录，自动包含子目录；分类标记默认为目录名称，可重命名。
3. 在“资源与数据”设置后台索引内存上限。默认 **512 MB（实际按 MiB 计）**，只限制索引进程。额度不足的文件会提示失败，可提高额度后重试。
4. 保存并关闭设置，点击“更新索引”。已完成文件立即保存；异常文件不会阻塞其他文件。
5. 目标1输入“张三”，目标2输入“上海”。同一行分别包含这两个目标即可，允许位于不同列，也允许同一个单元格同时满足。一个目标中的空格按原样匹配，例如“张三 上海”需要在一个单元格内连续出现。英文忽略大小写。

## 查看和复制

- 结果显示文件名、分类、工作表、真实行号、命中单元格坐标和预览。每页50行，可翻页；不预先计算昂贵的全部命中总数。
- 选中结果，下方显示命中单元格和文件完整路径。预览来自本地索引，不会重新读取 Excel。
- 双击文件名打开文件，双击文件路径打开所在文件夹，双击行号在 Microsoft Excel 中以只读方式打开并定位到对应工作表和行。该定位功能需要安装 Microsoft Excel；隐藏工作表或文件变动可能导致定位失败。
- 可复制命中单元格、整行或文件路径。复制整行保留列间空位，使用制表符分隔，可以粘贴到 Excel。
- “打开文件夹”定位原文件；“打开文件”或双击文件名使用系统关联程序。只有主动打开文件才可能启动 Excel。
- 左上方分类可缩小范围。“添加目标”最多支持16个目标，每个目标最多20字符，空框不参与查询；输入框随内容伸缩并自动换行。输入后250毫秒开始搜索，也可按回车。

## 日常更新和后台运行

- 新增、修改、删除文件后，手动点击“更新索引”。未变化文件按文件大小和最后修改时间跳过。若外部工具保留了这两项元数据，需清空并重建索引。
- “暂停/继续”保留当前进度；解析库正在读取内部结构时，响应可能延后。“停止”保存已完成文件，未完成的大文件下次重新读取。
- 最小化继续后台索引；关闭程序会停止任务并保存完成记录。没有默认开机启动或常驻更新服务。
- “失败文件 / 日志”查看原因，可重试全部未完成文件。旧文件重新索引失败时，已有的成功版本仍可搜索，并显示“旧索引”。
- 不读取密码加密文件，不执行宏，不重新计算公式。只搜索文件已保存的单元格值，包含隐藏工作表、隐藏行列和公式缓存。日期/数字参考保存格式，复杂条件格式及显示宽度不保证完全复现 Excel 画面。

## 索引数据管理

默认数据目录：`%LOCALAPPDATA%\WordFinder`。索引、配置、日志与 EXE 分离；替换兼容版本的 EXE 不会丢失分类和索引。支持通过内部测试参数 `--data-dir <目录>` 隔离数据，普通使用无需命令行。

“资源与数据”可以查看体积、打开数据目录、整理压缩、清空索引。移除分类只移除仅属于该分类的索引，源 Excel 保留。清空索引保留目录分类，之后点击更新索引重建。正常删除的空间可被后续索引复用；希望缩小数据库文件时使用整理压缩。整理需额外临时空间，更新时新旧版本也会短暂同时占用空间。

索引保存原文以支持预览和复制，当前不加密。索引只保存在本机；程序不上传 Excel 内容。索引稳定体积和峰值额度应由真实样本确定，合成测试比例不可直接用于预算。

## GitHub 更新

默认发布仓库为 `yishipi/WordFinder`，可在设置中更改。点击“检查软件更新”检查 GitHub 的最新正式 Release。发现新版后可打开发布页，自行下载匹配 x64 的 EXE。关闭程序后替换原 EXE 即可。联网失败不影响本机搜索。旧版本已保存的空仓库设置可手动填写 `yishipi/WordFinder`。

EXE 使用 SDK 单文件压缩并自带运行时；部分原生库首次运行需解包到用户临时目录，需要该目录可写。没有使用第三方加壳；当前构建未签名，尚未做目标办公电脑的杀毒软件验证。
